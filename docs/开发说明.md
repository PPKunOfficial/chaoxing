# 开发说明

## 安装与入口

开发环境要求 Python 3.13+：

```bash
python -m pip install -e .
chaoxing --help
```

安装后使用 `chaoxing` 命令；源码可运行 `python main.py` 或 `python -m chaoxing_app`。三种入口使用同一 CLI。配置文件参数示例：`chaoxing -c config.ini`。

## 代码结构

- `chaoxing_app/config.py`：参数解析与 INI 类型转换，不加载网络依赖。
- `chaoxing_app/cli.py`：登录、课程选择、通知与执行编排。
- `chaoxing_app/jobs.py`：章节任务、重试队列与工作线程生命周期。
- `api/`：平台协议、题库、通知及解码实现。
- `resource/`：随 wheel 分发的字体映射数据。
- `main.py`：源码和 PyInstaller 薄入口。
- `app.py`：独立 Flask/Celery 集成入口，不属于命令行执行路径。

## 验证

```bash
python -m unittest discover -s tests -v
chaoxing --help
uv build
```

离线回归覆盖配置转换与优先级、课程选择、重试上限、线程退出和异常传播。线上登录、直播和题库请求仍需要自己的账号及服务配置，不属于离线回归覆盖范围。

## 本次重构的行为变化

配置与调度从根脚本分离，统一包安装入口。INI 类型转换集中处理，CLI 的 `--retry-interval 0` 不再被默认值覆盖。

任务结束时关闭队列并回收全部工作线程；任务异常传播到调用方，空任务列表正常退出。章节内仍执行全部任务点后汇总失败结果，不因第一个失败而跳过后续任务。

进度格式在执行失败时也会恢复；字体资源路径不再依赖当前目录，支持安装后从仓库外启动。
