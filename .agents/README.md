# Agent 过程记录

本目录用于跨会话衔接，不替代项目约束或人类使用文档。

- [跨会话记忆](memory.md)：事实、出处和验证范围；续作时重新核对易变信息。
- [待办](todos.md)：待处理事项、授权边界和可验证的完成条件。
- [踩坑](pitfalls.md)：具体失败、原因与规避方法，区分复现与推断。
- [API 重构施工方案](api重构施工方案.md)：拟议分层、阶段验收和独立缺陷项。

规则只写入根目录 `AGENTS.md`；面向人的操作与决策正文写入 `docs/`。记录不包含凭据或未脱敏响应，方案与待办不自动授权实施；事实变化时更新原记录，禁止建立多份互相漂移的状态副本。
